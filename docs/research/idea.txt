Rootless Container Sandbox Scheduler for AI Agents	Every AI agent startup needs to execute untrusted, LLM-generated Python or Bash code safely. Spinning up cold containers per request is too slow, and standard Docker setups risk host escape.	A pre-warmed worker pool using rootless Podman (or Firecracker) with strict cgroup CPU/memory quotas, network egress locking, automatic container recycling, and real-time WebSocket TTY streaming back to the client.	Lovable, E2B, Cursor, Replit, Codegen, Devin/Cognition
